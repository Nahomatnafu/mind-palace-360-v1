# Fresh build plan

The finalized master prompt is the specification. Image-first creation, browser access without installation, and reliable local saving are the core. Practice, VR, accounts, and cloud sync are deferred.

1. Bootstrap a separate repository, pinned dependencies, test tools, shared models, and early deployment.
2. Evaluate Photo Sphere Viewer behind an adapter; build import, image placement, note reveal, and save.
3. Add room links, signed-coordinate editing, and validated ZIP backup.
4. Add protected OpenRouter suggestions/generation and permission-aware motion.
5. Verify desktop, mobile browser layouts, distinct-asset 118-marker density, and demo delivery.

App models are engine-independent. Repository saves a whole palace document with optional asset additions transactionally. Asset bytes remain Blobs. Fixed-screen-size memory markers are the default.

Networking and physical devices may block delivery checks; continue local development and report limits accurately. Private photos never enter public assets or Git history.
