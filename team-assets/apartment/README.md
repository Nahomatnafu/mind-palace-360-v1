# Apartment test palace (private team assets)

Shared by the owner's explicit request for collaboration in this private repository. Do not republish the photos, move them into public/, or make this repository public. The entire team-assets folder is excluded from Vercel deployments.

## Open the ready-made tour

1. Download [Apartment-9-photo-tour.zip](Apartment-9-photo-tour.zip) using GitHub's Download raw file button. Keep it zipped.
2. Open https://mind-palace-360-v1.vercel.app/ in the browser where you want to use the tour.
3. Open the palace-name menu at the top, choose **Restore ZIP**, and select the downloaded file.
4. The collection contains nine rooms and 16 editable navigation connections. Choose **Edit** to edit a connection or add a memory.

Each browser stores its own palace locally. Edits do not synchronize between teammates; use Export ZIP and Restore ZIP to exchange updates. GitHub access does not automatically import the palace into the app. AI requires the separate demo access code; obtain it from the project owner, not this repository.

## Source photos

Photo_1.jpg through Photo_9.jpg are exact copies of the supplied apartment JPEGs (1280 x 640), without additional compression. Photos 5 and 6 are identical in the source and both are retained. The ZIP contains these same original bytes, room names, and initial navigation links. No personal memory notes are included.

To build another tour from scratch, import the JPEGs using the app's room import control. For higher detail, request higher-resolution exports from the owner; storage hosting cannot recover detail absent from these supplied files.
